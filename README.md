# Marcenaria Arte-Sonho 🪵✨

Uma solução web estática, moderna e de alta performance desenvolvida sob medida para a **Marcenaria Arte-Sonho**. Este projeto funciona como um portfólio digital estratégico, focado em duas frentes principais: **exibir com excelência os trabalhos já realizados** e **transformar visitantes em novos clientes**.

## 🚀 Funcionalidades Estratégicas

- **Exibição Dinâmica de Projetos:** Galeria de fotos e seção de vídeos automatizadas locais via Node.js, garantindo que novos trabalhos sejam integrados rapidamente ao front-end sem codificação manual repetitiva.
- **Performance & Carregamento Fatiado:** Renderização via paginação progressiva (`slice`), otimizando o consumo de dados móveis e garantindo fluidez total em smartphones.
- **Captação Ativa de Leads:** Formulário de orçamento integrado nativamente com a API do WhatsApp.
- **Segurança e Privacidade:** Ocultação estrutural e ofuscação do número de telefone do cliente contra robôs de raspagem de dados (scrapers) e automação de remoção de metadados de imagens.

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript Vanilla (ES6+, `URLSearchParams`, `IntersectionObserver`)
- **Automação Back-end Local:** Node.js (módulos nativos `fs`, `path` e `crypto` com hash SHA-256 para prevenção de mídias duplicadas)
- **Hospedagem:** GitHub Pages (Ambiente estático seguro)
